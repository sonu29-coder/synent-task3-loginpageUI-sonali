# 🔐 Login Page UI

## 📌 Objective
A clean and modern login interface with properly aligned elements.

## 🚀 Features
- Email and Password input fields  
- Styled Login button  
- "Forgot Password" link  
- Responsive, centered layout  
- Gradient background with modern design  

## 🛠️ Tech Stack
- **HTML5**  
- **CSS3**  

## 📂 Project Structure
login-page/
│
├── index.html   # Main login page
└── style.css    # Styling for the UI

#code

## ⚙️ Setup & Run Instructions
1. Clone or download this repository.  
2. Open the project folder in **VS Code**.  
3. Run the `index.html` file in your browser (simply double-click or use Live Server extension).  

## 🌐 Output
- A modern login page with email & password fields, login button, and "Forgot Password" text.  
- Fully responsive and properly aligned UI.
